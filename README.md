# 🧬 Song DNA — 음악 링크 분석 프로토타입

음악 링크(Spotify · YouTube · Apple Music · Deezer)나 "아티스트 곡명"을 넣으면
곡을 찾아 **미리듣기 음원을 브라우저에서 직접 분석**하고, 결과를 인스타 스토리 비율(1080×1920)의
**공유용 Song DNA 카드**로 만들어 줍니다.

## 실행

```bash
npm start          # http://localhost:3000  (Node 18+, 설치할 의존성 없음)
npm test           # 오디오 분석 엔진 + 링크 파서 단위 테스트
```

## 무엇을 보여 주나

| 영역 | 내용 |
|---|---|
| 핵심 지표 | BPM, 키(장·단조), 캠롯 코드, 평균 음량, 다이내믹 레인지 |
| 사운드 프로필 | 에너지 · 댄스 · 긍정감 · 밝기 · 템포 · 다이내믹 · 어쿠스틱 (0~100) |
| 분위기 | 각성도 × 긍정감 4분면 → 신나는 / 강렬한 / 따뜻한 / 애잔한 |
| 에너지 흐름 | 시간에 따른 에너지 막대 + 최고점 + 전개가 바뀌는 지점(자동 구간 분할) |
| 음 분포 | 12음 크로마 분포 (으뜸음 강조) |
| DJ 믹싱 가이드 | 캠롯 휠 호환 키, ±6% BPM 범위, 하프/더블타임 |
| 곡 정보·크레딧 | 앨범, 발매일, 장르, 레이블, ISRC, 참여 아티스트 |
| 카드 | 앨범아트에서 추출한 5색 팔레트로 디자인, PNG 저장·공유 |

음악 파일(MP3/WAV/M4A)을 끌어다 놓으면 **서버로 업로드하지 않고** 브라우저 안에서 곡 전체를 분석합니다(최대 4분).

## 구조

```
server.js            정적 파일 + /api/resolve(링크→메타데이터) + /api/media(미디어 프록시, CDN 허용목록)
lib/resolve.js       링크 파싱, YouTube 제목 정리, Spotify 페이지 메타 파싱, Deezer/iTunes 조회·병합
public/analysis.js   오디오 분석 엔진 (FFT, 스펙트럴 플럭스 템포, Krumhansl 키, 체커보드 구간 분할)
public/card.js       k-means 팔레트 추출 + 캔버스 카드 렌더러
public/app.js        UI 흐름 · 상세 패널(SVG 차트) · 저장/공유
test/                합성 음원 기반 분석 정확도 테스트, 파서 테스트
```

### 링크 해석 방식 (API 키 불필요)
- **Deezer** 링크 → Deezer API 직접 조회 (BPM·게인·기여자·장르 포함)
- **Apple Music** → iTunes Lookup → Deezer에서 같은 곡 검색해 보강
- **Spotify** → 공개 트랙 페이지의 메타 태그에서 곡명·아티스트 추출 → Deezer/iTunes 검색
- **YouTube** → oEmbed 제목을 정리(`Official MV`, `[MV]`, 괄호 등 제거) → 검색
- 미리듣기 음원과 앨범아트는 CORS 때문에 `/api/media` 프록시를 거치며, 허용된 CDN 도메인만 통과합니다.
